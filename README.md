📊 Analyse de données avec Python (Pandas)
🧾 Description du projet

Ce projet utilise la bibliothèque Pandas pour analyser un fichier de données data.csv.
Le script permet de calculer différentes statistiques sur les ventes, les clients et les produits.

🛠️ Technologies utilisées
Python 🐍
Pandas 📊

Installation
Cloner le dépôt : git clone https://github.com/pathlib/data_analyste.git

Accéder dans le dossier : cd 

Installer les dépendances : pip install -r requirements.txt

Lancement
Exécuter l'application : python main.py


Projet
Développé dans le cadre d'un apprentissage de gestion de la data.
